# УП 01.01

Исполнитель - Оп.

Выполнение посредством реализации приложения из методической рекомендации с определёнными доработками до кондиции требований практики.

Описание:
WPF-приложение на .NET Framework 4.8 для Visual Studio 2026.

## Основной функционал
* Безопасность: Роли (Admin/User), хэширование паролей SHA1, графическая капча после 3 неудачных попыток входа, защита от копирования текста капчи.
* Учет: Интерактивное управление таблицами Пользователей, Категорий и Платежей через DataGrid (добавление, редактирование, каскадное удаление).
* Поиск: Динамическая фильтрация записей по ФИО, статьям расходов и хронологии.
* Аналитика: Столбчатая WPF-диаграмма с автоматическим масштабированием (устранил использование WinForms из-за проблем с ним).
* Экспорт отчетов: Выгрузка многостраничных документов в Microsoft Word (с автоконвертацией в PDF) и расчетных книг в Microsoft Excel.

## Как запустить
1. Развернуть базу данных в MS SQL Server (файл для создания в db/schema.sql).
2. Прописать валидную строку подключения к СУБД в App.config (секция <connectionStrings>).
3. Выполнить *Очистить решение* -> *Пересобрать решение* и запустить.# УП 01.01
